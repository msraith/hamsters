# Hamsters — карточка сервера

Сайт: https://msraith.github.io/hamsters/

Это постоянный публичный репозиторий карточки и инструкции игрока.

## Как обновить через GitHub

1. Откройте `index.html` и нажмите карандаш **Edit this file**.
2. Измените нужный текст, сохраняя HTML-разметку.
3. Нажмите **Commit changes**, укажите описание и сохраните в ветку `main`.
4. При изменении правил или установки обновите также `PLAYER_GUIDE.md`.
5. Дождитесь успешного выполнения **pages build and deployment** во вкладке
   **Actions**, затем откройте сайт и обновите страницу (Ctrl+F5).

GitHub Pages настроен на ветку `main`, каталог `/`. Дополнительная сборка
и платный хостинг не нужны. `index.html` — страница, `PLAYER_GUIDE.md` —
скачиваемая инструкция, этот README — инструкция владельцу.

## Что можно публиковать

В репозитории находятся только публичная карточка и инструкции. Клиентские
архивы пока не размещены; игроки обращаются к администратору. Не добавляйте
серверный рабочий каталог, резервные копии, данные игроков, секреты или `.evn`.
Перед размещением JAR/архивов отдельно проверяйте разрешения распространения.

## Как отменить неудачную правку

Откройте историю файла (**History**), найдите предыдущую рабочую версию и
скопируйте её содержимое в редактор текущего файла, затем сохраните новым
коммитом. Для локальной работы можно использовать `git revert`.
